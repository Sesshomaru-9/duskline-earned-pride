# Duskline Earned Pride

One line of earned pride for the make.fun bounty
**One Line of Earned Pride** (`u-mang-one-line-of-earned-pride-a0138557`).

## The entry

> Nine-year-old Lila, who had fallen off seven times, rode her bike past the corner shop without touching the brakes — and didn't look back to see if anyone was watching.

168 characters. A small person doing something hard: seven falls behind her,
one quiet ride past the corner shop, and pride that needs no audience — she
doesn't even look back to check if anyone saw. No trophy, no podium, no
graduation: just a kid, a bike, and a moment that lands in a single read.

## How to run

```sh
python3 main.py
```

`main.py` (Python 3.13 standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). It refuses with exit 1
if the output directory is inside this repository, since the grader sandbox
mounts the repo read-only.
